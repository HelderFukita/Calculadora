Elaborar uma calculadora

Nesse projeto professor pediu para criar uma calculadora que atenda algumas funcionalidades de acordo com seus objetivos.

#Requisito
  . Precisa que tenha todos os números de 0-9;
  . Todas as operações matemáticos de Soma, Diminuir, Dividir e Multiplicar;
  . Botões adicionais como porcentagem
  . Botão de apagar AC
  . Calculos com números inteiros ou quebrados
